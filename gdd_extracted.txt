## GAME DESIGN DOCUMENT
## Meta Connect &amp; Convert
Interactive Marketing Quiz Game
Event: August 18, 2026
Location: Pavilion Arena, Damansara Heights
## EXECUTIVE SUMMARY
Meta Connect &amp; Convert is an interactive, time-based quiz game that educates players about Meta's marketing solutions while delivering an engaging competitive experience. The game runs on multiple vertical touchscreen panels placed around the event venue, all connected to a lightweight API backend for data syncing and retrieval. Players answer a series of multiple-choice questions - each with a 30-second countdown - and their per-question scores are summed into a final score that is stored centrally and displayed on a shared, real-time leaderboard. All game content and rules (number of questions, the questions and answer choices themselves, points per question, and score display behaviour) are fully configurable by the event owner through a settings console, with no code changes required.
## 1. GAME OVERVIEW
## Game Concept
A fast-paced quiz game where players diagnose marketing problems and prescribe Meta solutions. Each question presents a business challenge, and players must identify the correct "A+ Strategy" from the answer choices within 30 seconds. The number of questions per game is set by the event owner, and questions are drawn at random from a configurable question pool so no two games feel the same.
## Target Audience
Meta marketing professionals, e-commerce businesses, digital marketers, and attendees at Meta Connect 2026 events.
## Objectives
• Educate players about Meta's marketing solutions (Placement, Audience, Creative, Shopping, Budget optimization)
• Create competitive engagement and social sharing
• Generate qualified leads through gameplay data
• Build brand affinity with Meta's marketing ecosystem
• Give the event owner full control of questions, scoring, and game length without developer involvement

## 3. QUESTION ROUNDS &amp; SCORING
## Question Rounds
• Each game presents N questions, where N is set by the event owner in settings (default: 5)
• Every question has its own 30-second countdown; answering or timing out advances to the next question
• At game start, the panel retrieves the active question pool from the backend and randomly selects N questions - the pool can hold more questions than needed (e.g., 10 configured, 5 used per game), so successive games get different question sets
• Answer choice order is shuffled on every question to discourage memorised answers
## Scoring System
• Each question has a base point value configured by the event owner (default: 100 points)
• Correct answer within 0-20 seconds: full base points
• Correct answer within 20-30 seconds: 75% of base points
• Wrong answer or time expiry: 0 points
• Perfect speedrun (all questions answered correctly in under 20s): +50 bonus points (configurable)
• Speed bonus is a global on/off setting - when turned off, any correct answer earns the question's full base points regardless of answer time
• Final score = sum of points earned across all questions (+ any bonus); the final score is submitted to the backend, stored, and ranked on the leaderboard
## Per-Question Score Display
After each question, the points earned are displayed alongside the correct/wrong feedback animation. The event owner can disable this in settings, in which case players see only right/wrong feedback during play and their total score is revealed at the end of the game.
## 4. EVENT OWNER SETTINGS (CONFIGURATION CONSOLE)
A separate, browser-based settings console (served by the API backend and protected by admin login) lets the event owner configure the entire game without code changes. Configuration is stored centrally; every touchscreen panel pulls the latest settings and question pool from the backend at the start of each game, so changes propagate to all panels automatically.

## Question Pool &amp; Randomization
• The event owner can configure more questions than a single game requires - for example, a pool of 10 questions when each game only uses 5
• At the start of every game, the required number of questions is drawn at random from the active pool, and the answer choices within each question are shuffled
• This keeps repeat plays fresh, reduces answer-sharing between players queuing at adjacent panels, and lets the owner rotate content during the event
• Validation: the console warns if the pool contains fewer questions than the configured questions-per-game value

## 9. TECHNICAL ARCHITECTURE
## System Overview
The system consists of multiple vertical touchscreen panels (clients) connected to a simple API backend for data syncing and retrieval. Each panel runs the game as a React application packaged as a desktop executable (.exe) via Electron, launched fullscreen in kiosk mode. At the start of each game the panel fetches the current settings and question pool from the backend; on completion it submits the final score (with a per-question breakdown). All panels receive leaderboard updates from the backend so rankings stay in sync across the venue.

## Environments &amp; Deployment
• API deployed on Vercel; Supabase provides the database, auth, and realtime layer
• A dedicated development endpoint (separate Vercel deployment + Supabase project) is available for development and testing without touching live event data
• The game client reads its API base URL from a config file, so the same .exe build can be pointed at the development or production endpoint
• Electron packaging via electron-builder produces a signed Windows .exe / installer for the panels
## Platform Requirements
• React game client packaged as a Windows executable (.exe) running fullscreen kiosk mode on each panel
• Portrait orientation, optimized for vertical touchscreen panels
• Settings console compatible with modern browsers (Chrome, Firefox, Safari, Edge)
• Multiple panels operating concurrently against the shared backend
• Offline tolerance: panels cache the last-synced question set and queue score submissions if connectivity drops briefly

## CONCLUSION
Meta Connect &amp; Convert combines entertainment with education, creating an engaging experience for marketing professionals at the event. Players answer a configurable series of timed questions, watch their scores add up, and compete on a live leaderboard synchronized across every touchscreen panel. Because the event owner controls the question pool, scoring, and game length through the settings console, the same platform can be refreshed mid-event or reused for future events without developer involvement.
